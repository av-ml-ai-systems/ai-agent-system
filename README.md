# AI Agent System

Educational AI Agent project focused on understanding how modern LLM applications are designed and implemented.

The objective of this repository is not to build the ultimate AI Agent, but to progressively understand the fundamental concepts behind Agentic Systems using software engineering principles.

---

# Project Objective

Build a simple educational AI Agent while learning:

- LangChain fundamentals.
- LLM application architecture.
- Prompt engineering.
- Structured outputs.
- Tool usage.
- Agent workflows.
- Conversation state.
- User interfaces.

The project follows an incremental learning approach:

```
Software Engineering Foundations

↓

LangChain Foundations

↓

Prompt Engineering

↓

Structured Outputs

↓

Tool-Using Agent

↓

Reasoning Workflow

↓

Memory

↓

Interfaces

↓

Portfolio Preparation
```

# Project Philosophy

This repository follows these principles:

- Educational before enterprise.
- Simplicity before complexity.
- Understand concepts before abstractions.
- One repository = one educational objective.
- Use LangChain when it provides clear educational value.
- Avoid unnecessary complexity and premature architecture.
